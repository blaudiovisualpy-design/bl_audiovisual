# Checklist visual obligatorio

UI/UX debe rechazar cuando:

- no coincide con las referencias visuales;
- Gemini Web detectó una dirección distinta;
- se mezclan estilos incompatibles;
- la interfaz parece una plantilla genérica;
- Stitch no fue utilizado;
- no existe responsive real;
- faltan estados, foco, accesibilidad o feedback;
- el resultado no está listo para cliente.
